# PureGlow Cleaning Solutions

A modern and responsive website for **PureGlow Cleaning Solutions**, a cleaning-products brand focused on providing a clean and fresh environment.

## 🌿 About the Project

PureGlow Cleaning Solutions is a product showcase website designed to present different cleaning products and services in a simple, attractive, and user-friendly way.

## ✨ Features

- Clean and modern light-green design
- Responsive layout for desktop and mobile
- Product showcase with realistic images
- About and Services sections
- Why Choose Us section
- Contact section for customer inquiries
- Smooth hover effects and navigation

## 🧴 Products

- Glass Cleaner
- Kitchen Cleaner
- Bathroom Cleaner
- Floor Cleaner
- Car Cleaner
- Surface Disinfectant

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- CSS
